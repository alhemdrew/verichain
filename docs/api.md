# API Overview

The VeriChain API exposes evidence, case, user, custody, and report operations through FastAPI routes.

## Core surfaces

- Auth and user management
- Case creation and listing
- Evidence upload, seal, verify, archive, vault, and report endpoints
- Custody verification and share operations

## Local operation

- Intended for local development and secure evaluation environments.
- Production secrets and signing keys must be managed outside the repository.
